# Ersagun Web Lab

Web geliştirmeyi sıfırdan öğreniyorum. Burada kendi yazdığım uygulamalar, ders notlarım ve küçük projelerim olacak.

HTML/CSS → JavaScript → Git/CI-CD → Cloudflare/DNS/Güvenlik sırasıyla ilerliyorum. GitHub'ın temel kullanımını ilk günden uyguluyorum.

## Eğitim ilerlemem

**2 / 20 kontrol noktası tamamlandı · %10**

| Bölüm | Tamamlanan | Bölüm ilerlemesi |
| --- | --- | --- |
| HTML / CSS | 2 / 5 | %40 |
| JavaScript | 0 / 5 | %0 |
| Git / CI-CD | 0 / 5 | %0 |
| Cloudflare / DNS / Güvenlik | 0 / 5 | %0 |

Bu oran yalnızca bu eğitimin tamamlanmasını gösterir. Uzmanlık seviyesi değildir. Uygulama ve mini sınav kontrol edilmeden ilerleme verilmez.

**Şu an:** HC02 tamamlandı. Başlık/paragraf kullanımına ek olarak bağlantıların görünen metni ile `href` hedefinin farklı olduğunu, tam dış bağlantılarda `https://` kullanımını ve göreli adres mantığını uyguladım.

**Sıradaki pratik:** Mevcut `uygulama.html` dosyasını tam bir HTML sayfasına dönüştürmek; `html`, `head`, `title` ve `body` bölümlerinin görevlerini öğrenmek.

## Nasıl çalışıyorum?

1. Kısa teoriyi okuyorum.
2. Uygulamayı kendim yazıyorum.
3. Küçük ödev ve mini sınavı tamamlıyorum.
4. Kodumu GitHub'a gönderiyorum; değişikliklerim kontrol ediliyor.
5. Eksikleri düzeltiyorum ve doğrulanan kontrol noktası kaydediliyor.

İlerleme kaydı ders sırasında güncellenir; arka planda otomatik değerlendirme yapılmaz. Asıl kayıt `progress.json` dosyasıdır. Bu README ve değerlendirme özeti onunla aynı tutulur.

## Araçlar

Windows, VS Code, GitHub Desktop ve bir web tarayıcısı. İlk dersler için paket yöneticisi, framework veya terminal kurulumu gerekmiyor.
