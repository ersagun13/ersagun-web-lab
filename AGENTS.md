# Eğitim reposunda çalışma kuralları

Bu repo başlangıç seviyesindeki öğrencinin uygulamalı web geliştirme eğitimi içindir.

- Önce README.md ve progress.json dosyalarını oku; yalnızca ilgili ders notlarını incele.
- Öğrenci Windows, VS Code ve GitHub Desktop kullanır. Yeni kavramları günlük Türkçe ile, küçük adımlarla açıkla.
- Sıra: HTML/CSS → JavaScript → Git/CI-CD → Cloudflare/DNS/Güvenlik. Temel GitHub kullanımını ilk haftadan itibaren pratik olarak göster.
- Her ders kısa teori, öğrenci uygulaması, küçük ödev ve mini sınav içerir.
- Öğrencinin uygulamasını ve açıklamasını kontrol etmeden kontrol noktasını passed yapma veya ona bağlı sonraki konuya geçme.
- Öğrenci yerine yazılan kodu öğrenci başarısı olarak kaydetme. Uygulama dosyalarını öğrenci yazsın; başlangıçta öğretmen yalnızca ders, repo düzeni ve değerlendirme kaydını hazırlasın.
- 20 eşit kontrol noktası vardır. Yüzdeyi passed sayısından hesapla; commit sayısı veya geçen gün başarı puanı değildir.
- progress.json asıl değerlendirme kaydıdır. README.md ve docs/PROGRESS.md onunla tutarlı kalmalıdır.
- Kanıtı kısa ve olgusal yaz. Özel sohbetleri, flörtöz konuşmaları veya kişisel ayrıntıları kamuya açık değerlendirme kaydına aktarma.
- Herkese açık dosyalarda token, şifre, .env, .dev.vars, özel/raw medya, müşteri bilgisi veya gizli sayfa adresi bulunmamalıdır.
- Gerçek sitenin private reposunu buraya kopyalama. Yalnızca ders için güvenle paylaşılabilen küçük kaynak örnekleri kullan.
- Bu repo ersagun.com.tr production hattına bağlı değildir. Eğitim amacıyla gerçek sitenin kodunu, mail/DNS ayarlarını veya erişim politikasını değiştirme.
- Public sitedeki ilerleme özeti ayrı bir yayın işidir; production doğrulanmadan yayında denmez.
- Başlangıçta gereksiz framework, bağımlılık, otomasyon veya uzun plan ekleme.
- Değişiklikleri inceleyip yalnızca gereken kontrolleri yap. Repo erişimi olan asistana .env veya giriş bilgisi isteme.
